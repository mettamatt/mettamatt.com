Privacy Policy

Retro Game Guides

Effective date: May 31, 2026

Retro Game Guides is built as an offline-first reader. The app does not require an account, does not include analytics or advertising SDKs, and does not send personal data to a Retro Game Guides server.

No account
No analytics
No ads or tracking
No cloud sync

Information the app stores locally

Retro Game Guides stores library data on the device so guides can be read offline. This can include game titles, platforms, imported or saved guide text, guide source URLs and attribution, favorite status, reading position, reader display settings, and custom sections created while using the app.

The app also uses local device preferences, including reader settings, library filters, and whether the GameFAQs browsing notice has been accepted. These preferences are used only to make the app work as expected on the device.

Information collected by the developer

The developer of Retro Game Guides does not collect, receive, sell, or share personal data from the app. The app has no developer-operated account system, analytics pipeline, advertising system, tracking system, or cloud-sync service.

Network requests and third-party services

Some features load content from third-party websites only when used. Those third parties may receive technical information that is normally sent with web or image requests, such as an IP address, user-agent information, requested URLs, cookies or website data, and other data described in their own privacy policies.

  • GameFAQs browsing and guide downloads: When the in-app GameFAQs browser is opened or a guide is saved from GameFAQs, the app loads pages from gamefaqs.gamespot.com. Saved guides are stored locally for personal offline reading. The developer does not receive the pages visited or guides saved.
  • Cover images: The app can request game cover images from URLs included in its bundled catalog. Cover images may be cached on the device. The developer does not receive cover image request data.
  • External links: Links opened outside Retro Game Guides are handled by the browser or app chosen by the device, and are subject to that app or website's privacy practices.

Files, folders, and clipboard

If files or folders are imported, Retro Game Guides reads only the items selected through the system file picker so it can add guides to the local library. The app does not scan unselected files.

If guide text is copied from the reader, the selected text is written to the system clipboard. The app does not read clipboard contents.

Device permissions

Retro Game Guides does not request access to location, contacts, photos, camera, microphone, health data, or advertising identifiers.

Retention and deletion

Local library data remains on the device until it is deleted in the app, removed by iOS cache management where applicable, or removed by uninstalling the app. Device backups are controlled by iOS and the user's Apple settings.

Children's privacy

Retro Game Guides is not designed to collect personal information from children. Because the app has no account system, analytics, advertising, or developer-operated cloud service, the developer does not knowingly collect personal information from children through the app.

Policy changes

If the app's privacy practices change, this policy will be updated with a new effective date.

Contact
